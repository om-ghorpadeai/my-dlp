\# My DLP – Pruthvi Group



A responsive Daily Lesson Plan (DLP) management system for Pre-Primary teachers.



\## 🌐 Live Demo



https://om-ghorpadeai.github.io/my-dlp/



\## ✨ Features



\- Create and save Daily Lesson Plans

\- Edit existing DLPs

\- Delete DLPs

\- Daily timetable view

\- Search subjects and topics

\- Responsive mobile-friendly design

\- Supabase database integration

\- GitHub Pages deployment



\## 📱 Mobile Support



The application is designed to work on desktop and Android devices.



\## 🛠️ Technologies



\- HTML

\- CSS

\- JavaScript

\- Supabase

\- GitHub Pages
